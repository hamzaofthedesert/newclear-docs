Adding Fitment Data

Fitment data is vehicle compatibility information — the list of specific year/make/model combinations that a part is compatible with. For auto parts listings on eBay, fitment data allows buyers to check if a part fits their vehicle before purchasing.

Prerequisites​

The Fitment tab only appears when a product is in an Auto Parts category. See Auto Parts Overview for how categories unlock this feature.

Accessing the Fitment Tab​

  1. Go to Products and open an auto parts product
  2. Click the Fitment tab at the top of the edit page

You'll see a table of fitment rows (empty if no fitment has been added yet).

Adding a Fitment Row​

  1. Click Add Row or the + button
  2. Fill in the fields:
FieldDescriptionRequired?
YearThe model year (e.g., 2018)✅ Required
MakeThe vehicle manufacturer (e.g., Ford, Toyota, Honda)✅ Required
ModelThe specific model (e.g., F-150, Camry, Civic)✅ Required
TrimThe trim level (e.g., Sport, Limited, XLT)Optional
EngineEngine specification (e.g., 2.5L I4, 5.0L V8)Optional
NotesAny additional fitment notesOptional
  1. Click Save Row or press Enter

Repeat for each compatible vehicle. A part may have dozens or hundreds of fitment rows if it fits many vehicles.

Editing a Fitment Row​

  1. Find the row in the fitment table
  2. Click the Edit (pencil) icon
  3. Make your changes
  4. Click Save

Deleting a Fitment Row​

  1. Find the row you want to remove
  2. Click the Delete (trash) icon
  3. Confirm deletion

Deleting a fitment row removes that vehicle from the compatibility list. On the next eBay sync, the updated fitment list is sent to eBay.

Fitment Source: Manual vs AI​

Each fitment row has a source indicator:

  • Manual — You added this row by hand or it came from a CSV import
  • AI — The row was generated by the AI Fitment Enrichment feature

The source is for reference only — both types work identically in listings. You can edit AI-generated rows the same as manual ones.

Adding Many Fitment Rows Efficiently​

For parts that fit many vehicles (e.g., a universal filter that fits hundreds of models), manual entry would take forever. Instead:

  1. Use AI Fitment Enrichment — Let the AI read the title/description and generate rows automatically. See AI Fitment Enrichment
  2. Use CSV Import — If you have fitment data in a spreadsheet, import it via the wizard with fitment columns mapped
  3. Copy fitment from a similar product — If multiple products have identical fitment, consider copying (contact support for bulk fitment tools)

How Fitment Affects eBay​

Every fitment row you add becomes a line in the ItemCompatibilityList XML sent to eBay. See Fitment & eBay Listings for how this works.

Tips​

tip

Be as specific as the part requires. A brake pad specific to the left front caliper of a 2016 Ford Mustang GT should have the Year=2016, Make=Ford, Model=Mustang, Trim=GT, Engine=5.0L V8. Specificity helps buyers confirm fit and reduces returns.

warning

Incorrect fitment data causes returns. A buyer who orders a part that doesn't fit their vehicle — because you listed it as compatible when it isn't — will return it and leave negative feedback. Verify fitment against the manufacturer's application guide.
