Troubleshooting the App

Common issues with the Newclear mobile app and how to fix them.

App Won't Open / Crashes Immediately​

Cause: Corrupted install or outdated APK.

Fix:

  1. Uninstall the app from your phone
  2. Download the latest APK from prod.newclear.io/connect
  3. Reinstall — make sure "Install from unknown sources" is enabled in your Android settings
  4. Log in again
iOS

iOS availability is coming soon. If you're on iPhone, use the web app at newclear.systems from your mobile browser in the meantime.

App Stuck on Loading Screen​

Cause: No internet connection, or session expired.

Fix:

  1. Check your internet connection (try loading a website)
  2. Force-close the app and reopen it
  3. If still stuck: log out and log back in
  4. If still stuck: uninstall and reinstall (see above)

Barcode Scan Not Working​

Cause: Camera permission denied, or barcode is too damaged to read.

Fix:

  1. Go to your phone's Settings → Apps → Newclear → Permissions
  2. Make sure Camera permission is set to Allow
  3. Restart the app and try scanning again
  4. If the barcode label is damaged or unreadable: use the manual entry field on the scan screen and type the UPC number directly

Can't See My Products​

Cause: An active seller filter is hiding products from other sellers.

Fix:

  1. Tap the filter icon on the inventory screen
  2. Check if a seller is selected — if so, clear it to show all sellers
  3. Also check the status filter — "Draft" products won't appear if filter is set to "Active only"
tip

If you only manage one seller, this usually isn't an issue. But if your company has multiple sellers, always check the filter first.

Products Not Syncing / Stale Data​

Cause: The app is showing cached data from a previous session.

Fix:

  1. Pull down on the product list to force a refresh
  2. If data still looks stale: force-close the app and reopen it
  3. Check your internet connection — the app needs an active connection to sync

Prints Not Going Through​

Cause: Newclear Connect isn't running, isn't paired, or is on a different network.

Fix:

  1. Open the computer running Newclear Connect — check the system tray for the Connect icon
  2. If it's not running: launch Newclear Connect from the Start menu / Applications folder
  3. Check that Connect shows as Connected (green status) — if not, log in again
  4. Make sure your phone and computer are on the same Wi-Fi network
  5. Try the print again

See Printing from Web & Mobile for a full troubleshooting guide.

Login / Authentication Errors​

Cause: Password changed, account deactivated, or token expired.

Fix:

  1. Try logging in again at newclear.systems on web to confirm your credentials work
  2. If you can log in on web but not mobile: force-close the app, clear app cache (Android Settings → Apps → Newclear → Storage → Clear Cache), then try again
  3. If your account was deactivated: contact your company admin

Still Having Issues?​

Contact support at support@newclear.systems and include:

  • Your phone model and Android version
  • A description of what you were doing when the issue occurred
  • Any error messages you saw
