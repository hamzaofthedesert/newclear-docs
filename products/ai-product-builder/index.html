AI Product Builder

The AI Product Builder is Newclear's built-in AI enrichment system that automatically fills in product details using artificial intelligence. Instead of manually writing descriptions, researching brands, or guessing categories — the AI does it for you in seconds.

What It Does​

When you click ✨ Enrich on a product, the AI Product Builder:

  1. Reads the product title and any other available fields (condition, category, existing description)
  2. Sends this to OpenAI (GPT-4o or similar model)
  3. Receives back structured product data
  4. Fills in missing or improves existing fields:
    • Description — Full marketing-quality product description
    • Brand — Identified from the title
    • Model — Specific model number or name
    • Category suggestion — If no category is set
    • Tags — Relevant keywords and attributes
    • Item Specifics — Key attributes for marketplace listings (color, size, material, etc.)

The whole process takes 5–15 seconds.

Requirements​

warning

The AI Product Builder requires an OpenAI API key configured in your settings. Without it, the Enrich button will be disabled or return an error.

Go to Settings > API Keys to add your key.

Using the Enrich Button on Web​

When creating a product:

  1. Fill in the Title field (at minimum)
  2. Click ✨ Enrich (usually shown as a sparkle/star button near the title or at the top of the form)
  3. Wait 5–15 seconds
  4. Review the AI-filled fields and edit anything that's wrong
  5. Save the product

When editing an existing product:

  • The ✨ Enrich button is always available on the edit page
  • Running it again will update/overwrite the existing description and fields with fresh AI output
  • Useful if you've improved the title or added more context since the product was created

Using the AI Builder on Mobile​

The mobile app has a dedicated AI Product Builder flow in the bottom navigation. See AI Product Builder (Mobile) for the full mobile walkthrough.

Confidence Scoring​

The AI returns a confidence score for certain fields. High-confidence results are applied automatically; lower-confidence suggestions may be flagged for your review. For example:

  • A product titled "Apple iPhone 14 Pro 256GB Space Black" → high confidence, fills everything
  • A product titled "Misc Electronics Lot" → low confidence, may leave fields blank
note

The AI never fabricates information it can't reasonably infer. If it's uncertain, it leaves the field blank rather than guessing wrong. You can always manually fill in anything the AI leaves empty.

Gemini Fallback​

If OpenAI is unavailable or rate-limited, Newclear will automatically fall back to Google Gemini (if you have a Gemini API key configured). The result quality is similar. You won't notice the switch — it happens transparently.

To configure Gemini: Settings > API Keys

What the AI Is Good At​

✅ Writing compelling product descriptions from a title
✅ Identifying brand and model from product names
✅ Suggesting appropriate categories
✅ Adding relevant search keywords as tags
✅ Describing conditions in marketplace-friendly language

What the AI Can't Do​

❌ Know your specific cost price or MSRP
❌ Guarantee 100% accuracy for niche or obscure products
❌ Replace actual product inspection (condition notes)
❌ Generate images (it works with text only in this flow)

Bulk Enrichment​

For large catalogs, you can select multiple products and run enrichment in bulk:

  1. Select products using checkboxes
  2. Click Bulk Actions > Enrich with AI
  3. The system queues enrichment jobs and processes them in the background

This is particularly powerful after a CSV import — import your full catalog first, then run bulk enrichment to fill in descriptions for everything.

Tips​

tip

Always review AI output before accepting it for live listings. The AI is very good but not infallible — especially for older products, niche items, or products with unusual names. Spot-check 10–20% of AI-enriched products initially.

tip

The better your title, the better the AI output. "Wireless Keyboard" gets a generic description. "Logitech MX Keys S Wireless Keyboard Graphite English" gets a detailed, accurate result.
