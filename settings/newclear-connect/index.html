Newclear Connect (Desktop App)

Newclear Connect is a small desktop application (built with Electron) that bridges your Newclear web/mobile app to your ZPL-compatible label printer. Without it, you can only print to a standard printer via your browser.

What Newclear Connect Does​

When you click "Print Labels" in Newclear, the print job needs to get to your physical printer. Newclear Connect is the bridge:

  1. Newclear web/mobile generates the label data
  2. Newclear Connect receives the print job on your local network
  3. Connect sends the ZPL commands to your label printer
  4. Label prints

Without Connect, the print job goes to your browser's standard print dialog (suitable for inkjet/laser printers, not thermal label printers).

Supported Printers​

Any ZPL-compatible thermal label printer:

  • Zebra — GK420d, GX420d, ZD420, ZT200, ZT400 series, and others
  • Dymo — LabelWriter series (via ZPL mode or direct integration)
  • Cognitive — ZPL-compatible models
  • Bixolon — Compatible models
  • Any other printer that accepts ZPL (Zebra Programming Language) commands
note

Regular inkjet/laser printers are NOT supported by Newclear Connect. They print via the browser's built-in print dialog instead.

Downloading Newclear Connect​

  1. Go to prod.newclear.io/connect in your browser
  2. Download the installer for your OS:
    • Windows — .exe installer
    • macOS — .dmg installer
  3. Run the installer and follow the setup wizard

Installing on Windows​

  1. Run the downloaded .exe file
  2. If Windows shows a security warning ("Windows protected your PC"), click More info then Run anyway
  3. Follow the installer prompts
  4. Newclear Connect opens automatically after install

Installing on macOS​

  1. Open the downloaded .dmg file
  2. Drag Newclear Connect to your Applications folder
  3. Open from Applications
  4. If macOS shows a security warning, go to System Settings > Privacy & Security and click Open Anyway

Pairing with Your Account​

The first time you open Newclear Connect, you'll need to pair it with your Newclear account:

  1. Open Newclear Connect
  2. Click Sign In or Pair Account
  3. Enter your Newclear email and password (or use a pairing code from the web app)
  4. Your company account is linked to this installation of Connect

Connecting Your Printer​

  1. In Newclear Connect, go to Printers or Settings
  2. Click Add Printer
  3. Connect your ZPL printer via USB or ensure it's on the same network (network printers)
  4. Select the printer from the detected devices list
  5. Give it a name (e.g., "Front Desk Zebra")
  6. Save

System Tray​

Once installed and running, Newclear Connect minimizes to the system tray (Windows taskbar / macOS menu bar):

  • The tray icon shows Connect is running and ready
  • Right-click the tray icon to open, pause, or exit
  • Green icon = connected and ready
  • Yellow/red icon = issue to investigate

Auto-Launch​

Newclear Connect is configured to auto-launch on startup by default so it's always running when you turn on your computer. You can disable this in Connect's settings if needed.

Auto-Update​

Newclear Connect automatically checks for updates and installs them in the background. You'll see a notification when an update is available. Most updates happen without interrupting print jobs.

Tips​

tip

Install Newclear Connect on the computer physically connected to (or closest to) your label printer. The computer running Connect must be on the same local network as the device making the print request (web browser or mobile app).

warning

If Connect isn't running, print jobs from Newclear won't reach your ZPL printer. A common issue is Connect not auto-launching after a computer restart. Check the system tray before troubleshooting print failures.
