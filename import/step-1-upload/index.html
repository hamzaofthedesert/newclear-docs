Step 1 — Upload

The first step of the Import Wizard is uploading your CSV file and selecting the Seller the imported products will belong to.

Uploading Your CSV File​

  1. Click Choose File or drag and drop your CSV file into the upload area
  2. The file uploads immediately

After uploading, a 5-row preview appears below the upload area showing the first five rows of your file with column headers. This helps you verify:

  • The right file was selected
  • Columns look correct and data is readable
  • There are no encoding issues (garbled characters)
tip

If the preview shows garbled characters or columns look wrong, your CSV may not be UTF-8 encoded. Open the file in a text editor, save as UTF-8, and re-upload.

Selecting Your Seller​

Below the preview, you'll see a Seller dropdown. This is required — you must select which Seller all the imported products will belong to.

  1. Click the Seller dropdown
  2. Select the appropriate Seller
  3. If you need to create a new Seller first, go back to Settings > Sellers
warning

All products in this import will be assigned to the selected Seller. If you're importing products for two different sellers, run separate imports for each.

CSV Format Requirements​

Your CSV file should follow these guidelines:

  • Encoding: UTF-8 (avoid Windows ANSI encoding which causes character issues)
  • First row: Column headers (e.g., "Title", "Price", "SKU")
  • Delimiter: Comma-separated (.csv not .tsv)
  • Text with commas: Wrap in quotes: "Nike Running Shoes, Men's"
  • Dates: ISO format recommended: 2024-01-15
  • Numbers: No formatting (avoid $47.00 — use 47.00)
  • Line breaks in descriptions: Supported if properly quoted

Auto Template Detection​

When you upload a file, Newclear analyzes the column headers (the "fingerprint" of the file) and checks whether it matches any of your saved Import Templates.

If a match is found:

  • A banner appears: "Template 'Target Manifest' detected — applied automatically"
  • Column mappings from the template are pre-filled in Step 2
  • You can review and adjust, or proceed directly

This saves significant time when you regularly import from the same source (e.g., the same B-Stock supplier's manifest format).

File Size and Row Limits​

  • No hard row limit — large files (thousands of rows) are supported
  • Very large files (50MB+) may take longer to process
  • If you have an extremely large file, consider splitting it into batches of 1,000–5,000 rows

Clicking Next​

Once you've uploaded the file and selected a Seller, click Next to proceed to Step 2 — Column Mapping.

note

You can go back at any step and make changes. Your progress is retained when navigating between steps within the same session.
