Liquidation Orders

A Liquidation Order is automatically created when you run a B-Stock import. It groups all the products from that import under a single tracked lot — giving you a way to manage, monitor, and report on each liquidation purchase as a unit.

What a Liquidation Order Is​

Think of a Liquidation Order as the "container" for a single pallet or lot purchase:

  • All products imported from that CSV are linked to the order
  • The lot cost is stored on the order
  • As products sell, the P&L for the lot is calculated
  • You can see at a glance how much of the lot has sold and what your ROI is

Where to Find Liquidation Orders​

  1. Go to Liquidation or Reports > Liquidation in the sidebar
  2. Click Liquidation Orders

The list shows all your lots with:

  • Liquidation Order Number (your reference from the import)
  • Retailer name
  • Import date
  • Total lot cost
  • Number of products
  • Status (Active, Sold Out, etc.)

Click any row to open the order detail.

Liquidation Order Detail Page​

Opening a liquidation order shows:

Summary Stat Cards​

At the top, at-a-glance metrics:

  • Total Products — Items in this lot
  • Sold — Items sold so far
  • Revenue — Total sales from this lot
  • Lot Cost — What you paid
  • Gross Profit — Revenue − Lot Cost
  • ROI % — Return on investment

Product Table​

A table of all products linked to this lot:

  • Product title and SKU
  • Condition
  • MSRP (if set)
  • Cost (allocated from lot cost)
  • Selling price
  • Status (sold, in stock, out of stock)
  • Revenue generated

You can click any product to open it in the Products editor.

Status and Notes​

The order has:

  • Status field — Update to reflect the lot's current state (Active, Sold Out, Archived, etc.)
  • Notes — Add any internal notes about the lot (where it came from, special handling, etc.)

Both status and notes are editable — click to modify and save.

Creating a Liquidation Order Manually​

You can also create a Liquidation Order without running an import:

  1. Go to Liquidation > Orders
  2. Click New Order
  3. Fill in:
    • Order Number
    • Retailer
    • Lot Cost
    • Date
    • Notes
  4. Manually link products by adding them to the order

This is useful for lots you received physically but weren't imported via CSV (e.g., received via POW from another company).

How Liquidation Orders Feed P&L Reports​

The Liquidation Order is the link between your products and the Liquidation P&L Report. As products in the lot are sold:

  • Revenue accumulates against the lot
  • Profit is calculated vs lot cost
  • The P&L report shows your recovery rate (revenue as % of lot cost)

Tips​

tip

Always use a meaningful Lot Number when importing — ideally the actual auction order number from the B-Stock marketplace. This makes it easy to trace a product back to its source lot if needed.

tip

Update the Status of lots as they progress. Marking old lots as "Archived" or "Sold Out" keeps your active lot list clean and focused on what you're currently working.
