Import Templates

Import Templates save your column mapping configuration so you don't have to re-map columns every time you import from the same supplier or source. Templates are detected automatically when you upload a matching file.

What Templates Save​

A template stores the complete configuration from Steps 2–4 of the Import Wizard:

  • Column Mappings — Which CSV column maps to which Newclear field, and which columns are Ignored
  • Constant Values — Any columns set to Constant and their values
  • Mass Options — Default status (Active/Draft) and price adjustment settings
  • B-Stock Settings — B-Stock mode on/off, pricing % (lot cost is NOT saved — entered fresh each time)

What Templates Do NOT Save​

  • The CSV file itself
  • Seller selection
  • Lot cost (for B-Stock — this changes every import)
  • Row data or product values

Auto-Detection by File Fingerprint​

When you upload a CSV in Step 1, Newclear analyzes the column header fingerprint — the set and order of column names in your file. This fingerprint is compared against your saved templates.

If a match is found:

  • A banner appears at the top: "Template 'Target Manifest' detected and applied"
  • Column mappings are pre-filled automatically in Step 2
  • You proceed directly to review the pre-filled mappings

This saves 5–10 minutes per import for frequent importers.

Saving a Template​

During Step 5 (Review & Submit):

  1. Check Save as Template
  2. Enter a name for the template
  3. Submit the import (or save without submitting)

The template is saved and available for all future imports.

Managing Templates​

To view, edit, or delete saved templates:

  1. Go to Products > Import
  2. Look for a Templates link or button
  3. The Templates list shows all saved templates with:
    • Template name
    • Date created
    • Column count
    • B-Stock enabled indicator
  4. Click a template to preview its mappings
  5. Click Delete to remove it

Applied Template Badge​

When a template is auto-applied to an import, a badge appears near the column mapping header in Step 2 indicating which template is active. This confirms you're using the correct mapping before proceeding.

You can still make changes to the auto-applied mapping — templates are a starting point, not locked settings.

Common Template Names​

Examples of templates businesses save:

  • "B-Stock Target Manifest" — For Target returns pallets
  • "Supplier ABC Catalog" — Specific supplier's weekly catalog
  • "eBay Export" — eBay's Selling Manager Pro export format
  • "Shopify Export" — Shopify's product export format
  • "Custom Wholesale Supplier" — Your unique supplier's spreadsheet

Tips​

tip

Name your templates clearly with the source name. "Template 1" tells you nothing in 3 months. "Direct Liquidation - Electronics Manifest" is immediately clear.

tip

If a supplier changes their CSV format (adds or removes columns), your existing template may not auto-detect correctly. Update the template by running a new import, adjusting the mapping manually, and re-saving as a template (overwrite the existing one).

note

Templates are company-wide — all users in your company can benefit from saved templates. If someone on your team has already configured a template for your main supplier's format, you don't need to recreate it.
