Step 2 — Column Mapping

Column Mapping tells Newclear what each column in your CSV file represents. For every column, you choose whether to Map it to a Newclear field, Ignore it, or set a Constant value for all rows.

Understanding the Mapping Interface​

The mapping screen shows a row for each column in your CSV file:

  • Column Name — The header from your CSV (e.g., "Product Title", "MSRP", "ITEM-ID")
  • Sample Value — The actual value from the first 1–3 rows of your file
  • Action — What to do with this column:
    • Map — Connect it to a Newclear field
    • Ignore — Skip this column (don't import it)
    • Constant — Set the same value for every row (overrides the column's data)
  • Newclear Field — Which Newclear field this maps to (only shown when Action = Map)

Available Newclear Fields​

You can map columns to the following Newclear product fields:

Tips for Common CSV Formats​

Manifest from B-Stock / Liquidation Auction​

Common columns and their mappings:

  • "Product Title" → title
  • "MSRP" or "Retail Value" → msrp
  • "Item UPC" → upc
  • "Category" → category (may need review — categories must exist in Newclear)
  • "Quantity" → quantity
  • "Mfr. Part Number" → vendor_sku
  • "Condition" → condition

eBay Seller Hub Export​

  • "Custom label (SKU)" → prod_sku
  • "Title" → title
  • "Start price" → price
  • "Quantity available" → quantity

Shopify Product Export​

  • "Title" → title
  • "Variant SKU" → prod_sku
  • "Variant Price" → price
  • "Variant Compare At Price" → msrp
  • "Image Src" → image_url
  • "Variant Inventory Qty" → quantity

Using Ignore and Constant​

Ignore: Click Ignore for columns you don't need in Newclear (e.g., internal auction IDs, pallet numbers, notes that don't belong in product records).

Constant: Useful for setting the same value on every product:

  • Set condition = "Used" for an entire used-goods manifest
  • Set status = "Draft" for a batch you're not ready to make live yet

Saving and Loading Mappings​

If you've saved a Template from a previous import, it auto-applies when the file fingerprint matches. You can also manually select a template to apply at this step.

After setting up mappings, click Next to proceed to Step 3 — Mass Options.

tip

Spend extra time on this step to get it right. A wrong mapping (e.g., mapping "Cost" to "price" instead of "cost") can create products with incorrect prices. The 5-row preview helps you verify the values look right before submitting.
