Troubleshooting Channel Sync

Most channel sync issues have simple causes. This guide covers the most common problems and how to fix them quickly.

Product Not Appearing on Channel​

Check 1: Product Status​

The product must be Active (not Draft) to be pushed to any channel.

  1. Open the product
  2. On the Details tab, check the Status field
  3. Change to Active if needed and Save

Check 2: Category Mapping​

For eBay especially, the product's category must have a valid eBay mapping.

  1. Go to Settings > Categories
  2. Find the product's category
  3. Check the eBay mapping status
  4. If it's Unmapped or Failed, set the mapping manually (see Categories)

Check 3: Missing Required Fields​

Products missing required fields won't push to some channels:

  • eBay: Must have images, price, quantity > 0, valid category mapping
  • Amazon: Must have UPC, price, quantity > 0
  • Walmart: Must have UPC, images, brand, price

Open the product and complete any missing fields.

Check 4: Channel Disconnected​

If the channel was disconnected and reconnected, products may need to be re-pushed.

  1. Go to the product's Channels tab
  2. Find the channel
  3. Click Push or Re-list

Inventory Not Syncing​

Symptom: Sold something on eBay but Newclear quantity didn't update​

  1. Check if the order was imported in Orders
  2. If the order is there, inventory should have decremented — check the product's current qty
  3. If the order isn't imported, check if the channel connection is still active

Symptom: Newclear quantity changed but channel didn't update​

  1. Go to Settings > Channels for the affected channel
  2. Look for any sync errors or "last synced" timestamp
  3. Try a manual Resync Inventory if available
  4. Check if the channel API credentials are still valid (they can expire)

Listing Errors​

"Invalid category" or "Category not found"​

  • eBay category IDs change periodically. The mapped eBay category may have been deprecated
  • Go to Settings > Categories > re-map the affected category
  • 👉 See Categories

"Missing required item specifics"​

  • The eBay category requires specific fields (like Size, Color, Material) that aren't filled in
  • Open the product, add the missing specifics in the item specifics fields
  • Re-push after saving

"Price too low"​

  • eBay and Walmart have minimum price requirements for some categories
  • Raise the product price above the minimum
  • Different categories have different minimums — check eBay's Help for the specific category

"Invalid condition for category"​

  • Some eBay categories only allow certain conditions (e.g., collectibles must be "Used")
  • Change the product condition to one supported by the category

Authentication error / Token expired​

  • OAuth tokens can expire, especially for eBay
  • Go to Settings > Channels > [channel] > Disconnect and reconnect
  • Follow the OAuth flow again to get a fresh token

Re-syncing Manually​

For most channels, you can trigger a manual sync:

  1. Go to Settings > Channels
  2. Click on the channel
  3. Look for a Sync Now, Resync Inventory, or Re-push All button
  4. Confirm — the sync runs in the background
note

Large catalogs may take several minutes to fully sync. Don't trigger multiple syncs in a row — wait for the first one to complete.

Still Having Issues?​

  1. Check the channel's own dashboard (eBay Seller Hub, Amazon Seller Central, etc.) for any account-level issues or restrictions
  2. Check if there are any Newclear service notifications
  3. Contact Newclear support with:
    • The product SKU(s) affected
    • The channel name
    • The error message (if any)
    • When the issue started
tip

For eBay errors, always copy the exact error message shown in Newclear. eBay's error codes are specific and support can diagnose them quickly.
