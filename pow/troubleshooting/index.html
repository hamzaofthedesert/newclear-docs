Troubleshooting POW

Most POW issues are related to SKU mismatches, seller configuration, or transfer status confusion. Here are the most common issues and how to resolve them.

"Already in Progress" Message​

Symptom: When trying to open or start a transfer, you see "Already in progress" or a similar message.

Cause: This appears when a transfer is currently being received by another session or user. If two people try to receive the same transfer simultaneously, the second person sees this message.

Fix:

  1. Check if a colleague is actively working on this transfer
  2. If yes: wait for them to complete or save as draft before you open it
  3. If no (the session was abandoned): Try refreshing the page. If the message persists, contact support — the transfer may be stuck in a "locked" state that needs to be cleared

Products Not Appearing After Create All​

Symptom: You clicked Create All, the process completed, but you can't find the new products in your catalog.

Check 1: Seller Filter
The most common cause. If you're filtering Products by a specific seller, and the received products went to a different seller, they won't show.

  • Remove all filters on the Products page (or select "All Sellers")
  • Sort by Date Added to see newest products first

Check 2: Status Filter
New products received via POW may come in as Draft status. Filter by Status = Draft to find them.

Check 3: Did Create All Actually Complete?
Look for the result summary screen. If it was dismissed or the page refreshed during processing, the products may not have been fully created.

  • Check the transfer — is it marked as Complete or still Pending?
  • If still Pending, run Create All again

Check 4: Network Issue
If you lost internet during Create All, some products may not have been created.

  • Wait 5 minutes and check again
  • Re-open the transfer and run Create All again — it's safe to run multiple times (duplicate protection prevents double-counting)

SKU Not Found When Scanning​

Symptom: You scan a product's barcode and get "SKU not found" or "Product not matched."

Check 1: Scan Both SKU Types
Newclear checks prod_sku first, then vendor_sku. If the barcode encodes the sender's prod_sku, it matches as your vendor_sku. Make sure the vendor_sku field is populated on your catalog products.

Check 2: Manual SKU Search
Instead of scanning, manually type or paste the SKU in the search field. If the manual search also fails, the product doesn't exist in your catalog.

Check 3: Product Doesn't Exist Yet
If this is a new product being received for the first time, it won't be in your catalog. Use Create All to let Newclear create it from the transfer data.

Check 4: Barcode Encoding Issue
The barcode on the product may encode a UPC, not an SKU. Try scanning in a different context (Products search bar) to see what the barcode decodes to.

Transfer Showing as Pending When Already Received​

Symptom: You completed a transfer, but it still shows as Pending in your transfer list.

Fix:

  1. Refresh the POW tab (pull down to refresh on mobile, or reload the page on web)
  2. If still showing Pending after refresh: open the transfer and click Mark as Complete if the button is available
  3. If you can't find the transfer at all, it may have been archived — check for a "Completed" filter on the transfer list

Received Wrong Seller​

Symptom: Products from a transfer went to the wrong seller.

Fix:

  1. Go to Products
  2. Filter by the wrong seller and sort by Date Added
  3. Find the affected products
  4. Open each product and change the Seller to the correct one
  5. Save

For large transfers, this is tedious. Prevention is better — always check the Seller setting in POW before receiving. See Selecting Your Seller.

tip

If you frequently receive to the wrong seller, set a daily reminder to check the POW seller setting at the start of each shift.
